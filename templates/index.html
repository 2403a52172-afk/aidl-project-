How the Deepfake Detection Pipeline Works

End-to-end mathematical audio processing and deep neural network inference

1. Audio Normalization

Audio is standardized to 16 kHz mono, peak normalized, and framed to 4.0 seconds (64,000 samples).

2. Log Mel-Spectrogram

Computes 128 Mel frequency bins with FFT window 1024 to convert audio into a 128x128 2D spatio-temporal map.

3. 2D CNN Architecture

4 convolutional blocks with BatchNorm, ReLU, and Dropout extract neural vocoder phase and harmonic anomalies.

4. Forensic Verdict

Softmax outputs REAL vs FAKE probabilities, confidence scores, and an audit report with spectral visuals.
